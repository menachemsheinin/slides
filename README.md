# מצגות · כלים דיגיטליים א׳

אתר מצגות נפרד מאתר הקורס.

## הצגה במחשב אחר (בלי התקנה)
לוחצים פעמיים על **`present.bat`**. הוא עובד בכל מחשב Windows: משתמש ב-Python אם מותקן, ואחרת בשרת מובנה של PowerShell, ואם גם זה נחסם פותח את `index.html` ישירות (במצב כזה סרטוני YouTube לא יתנגנו). צריך להשאיר את החלון השחור פתוח בזמן ההצגה.
העתקת התיקייה כולה (`slides`) למחשב אחר מספיקה. **עריכה ושמירה** דורשות Python (`edit.bat`).

## עריכה
לוחצים פעמיים על `edit.bat` (דורש Python). נפתח הדפדפן עם מצב עריכה. אחרי הרצה ראשונה אפשר לסגור את חלון הפקודות כשמסיימים.

- **ערוך** בכרטיס של מצגת, או **עריכה** בסרגל הכפתורים בזמן הצגה (נפתח באותו שקף).
- ברשימה מימין: הוספה, מחיקה, שכפול והזזה של שקפים. באמצע: תצוגה מקדימה חיה. משמאל: שדות העריכה של השקף שנבחר.
- תמונות: מעתיקים תמונה (מ-PowerPoint, מדף אינטרנט, צילום מסך או מכל מקום) ולוחצים **Ctrl+V** בעורך. התמונה נכנסת לשדה התמונה שנבחר, אחרת לשדה ריק בשקף, ואם אין בשקף שדה תמונה נפתח שקף תמונה חדש.
  אפשר גם **לגרור**: לשדה תמונה ספציפי, לתצוגה המקדימה (בשקף ההשוואה: צד שמאל או ימין לפי המקום שבו שחררתם), לרשימת השקפים (נוצר שקף תמונה חדש), או לכל מקום אחר בחלון. גרירה של כמה תמונות יחד יוצרת שקף לכל אחת. גרירה מדף אינטרנט עובדת גם כשהדפדפן נותן רק כתובת, והשרת מוריד את התמונה (רק מכתובות ציבוריות). הקבצים נשמרים ב-`assets/img`.
- סרטון: מוסיפים שקף מסוג ״סרטון (קוד הטמעה)״ ומדביקים קוד הטמעה (iframe) או קישור. YouTube, Vimeo, Google Drive וקישור ישיר לקובץ mp4 נתמכים. קוד שמכיל סקריפט לא נתמך. צריך אינטרנט. YouTube לא מתנגן כשהמצגת נפתחת כקובץ (שגיאה 153, כי אין כתובת מפנה): להציג דרך edit.bat (כתובת localhost). בפתיחה כקובץ מוצגת תמונה ממוזערת וקישור לפתיחה ב-YouTube. אחרי לחיצה בתוך הסרטון המקשים עוברים אליו; לוחצים על הרקע של המצגת כדי להחזיר אותם.
- **שמור** (או Ctrl+S) כותב ישר לקובץ המצגת. ״בטל״ ו״שחזר״ עובדים גם אחרי שינויים גדולים. לפני כל שמירה נשמר גיבוי ב-`decks/_backup` (30 אחרונים).
- בכרטיס ״בקרוב״ של מפגש אחר: **צור מצגת**.

## הצגה
פותחים את `index.html` (גם בלי edit.bat) או דרך edit.bat.

| מקש | פעולה |
|---|---|
| ← או רווח | הבא (בעברית מתקדמים שמאלה) |
| → | הקודם |
| F | מסך מלא |
| O | תוכן המצגת |
| N | הערות מרצה (Esc לסגירה) |

## מבנה הקבצים
- `decks/<id>.js`: תוכן מצגת, קובץ טקסט שהעורך כותב. אפשר לגבות או להעתיק.
- `decks/manifest.js`: רשימת 12 המפגשים.
- `assets/slides.js`: סוגי השקפים. הוספת סוג חדש מתבצעת שם.
- `serve.py`: השרת המקומי, מאזין רק למחשב הזה.
